> SOBRE ESTA API

Locos API es un proyecto de Locos y asociados. Esta versión incluye endpoints básicos de prueba, respuesta JSON y documentación. Los futuros módulos se podrán añadir sin cambiar el diseño del panel.

Los servicios de descarga, inteligencia artificial u otras funciones todavía no están programados. Esta página muestra únicamente las rutas que existen actualmente.

DOCUMENTACIÓN_

Locos API utiliza HTTP y JSON. Los endpoints actuales no necesitan API key. Esto puede cambiar si se incorporan servicios nuevos.

03 / EJEMPLO POST

      
Enviá JSON usando el encabezado Content-Type: application/json.
Respuesta esperada:
{"ok":true,"message":"hola"}

      
04 / ERRORES COMUNES

      
400 — JSON inválido o campos incorrectos.
404 — El endpoint solicitado no existe.
415 — Falta el encabezado de JSON en solicitudes POST.
429 — Se alcanzó el límite de peticiones.
500 — Error interno del servidor.
Las respuestas reales dependen del estado del servidor y de la solicitud enviada.
